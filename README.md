## 📦 What's Inside

This open-source package includes everything you need to explore and customize your own city sustainability dashboard:

- **Full .pbix file** – The complete Power BI report
- **TMDL model** – The underlying data model structure
- **223 DAX measures** – Organized into folders for easy navigation  
- **74 HTML components** – Custom visual elements and tooltips
- **Custom theme** – A professional visual theme for consistent look

## 🔧 Next Steps – Customize

Once opened, you can:

- **Connect to your own city data** – Use **Home > Get Data** to import Excel, CSV, or database sources  
- **Modify DAX measures** – Go to **Model view** and adjust formulas for your needs  
- **Change visuals** – Right-click and select **Update** or format options
- **Share your dashboard** – Publish to Power BI Service (requires subscription)
